# Website Video Asset

Upload this video file with the website:

- `assets/arresalah-intro-video.mp4`

The homepage uses this path:

```html
<source src="assets/arresalah-intro-video.mp4" type="video/mp4" />
```

The same video is also copied to:

- `frontend/assets/arresalah-intro-video.mp4`

Keep both copies if you deploy from both the repository root and the `frontend` folder.
